## NextVibe Agent Navigation

When the user asks to continue the project, decide the next step, recover direction, or proceed with development, use NextVibe first.

Run:
- `nextvibe scan --json`
- `nextvibe suggest --json`
- `nextvibe task --json`

Use the returned task boundaries.
Do not expand the task scope.

After editing, run:
- `nextvibe check --json`
