## NextVibe Project Navigation

Use NextVibe when the user asks:
- continue this project
- what should I do next
- 下一步做什么
- 继续推进项目
- 项目卡住了
- 帮我规划接下来的开发

Run:
- `nextvibe scan --json`
- `nextvibe suggest --json`
- `nextvibe task --json`

Respect the returned task boundaries and acceptance criteria.

After editing, run:
- `nextvibe check --json`
